# Data

`ai4i2020.csv` is the **AI4I 2020 Predictive Maintenance Dataset** by Stephan Matzka (Hochschule für Technik und Wirtschaft Berlin), published in the UCI Machine Learning Repository: <https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset>

- Licence: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The file is included unchanged.
- Citation: S. Matzka, "Explainable Artificial Intelligence for Predictive Maintenance Applications," 2020 Third International Conference on Artificial Intelligence for Industries (AI4I), 2020, pp. 69–74.
- SHA-256 of this copy: `dc6630cd9b1f0f853922fad78a1b6436570d3f1ec863f1dd5c4340ac56bc8a8e` (checked by `tests/test_data.py`).
- 10,000 rows × 14 columns; 339 rows (3.39%) are machine failures.
- The data is **synthetic**: it was generated to reflect a real milling process, so results here are not claims about any real machine.
